แพ็กเกจสำรองจาก Site ที่เผยแพร่แล้ว

Site ต้นทาง:
https://scenery-cashier-close-round.phummiphat582.chatgpt.site/

ไฟล์ในชุดนี้เป็นไฟล์ที่เข้าถึงได้จากหน้าเว็บที่เผยแพร่แล้ว ได้แก่ HTML, CSS,
JavaScript ฝั่งหน้าเว็บ, ไฟล์ manifest, ไฟล์ข้อมูล invoice-source และรูปภาพที่ตรวจพบ

ข้อจำกัดสำคัญ:
- ชุดนี้ไม่ใช่ Export โปรเจกต์ต้นฉบับจาก ChatGPT
- ไม่รวมฐานข้อมูล Supabase จริง ประวัติการทำรายการ บัญชีผู้ใช้ หรือข้อมูลลับบนเซิร์ฟเวอร์
- ค่า Secret/API key ต้องตั้งค่าใหม่ในบัญชีหรือบริการปลายทางด้วยตนเอง
- ห้ามเผยแพร่ไฟล์นี้ต่อสาธารณะโดยไม่ตรวจสอบข้อมูลภายในก่อน

แนวทางย้าย:
1. แตกไฟล์ ZIP
2. ตรวจสอบ app.js, master-data.js, supabase-config.js และ invoice-source.txt
3. สร้าง Site ใหม่ในบัญชีปลายทางที่รองรับ Sites
4. อัปโหลดไฟล์เหล่านี้หรือเชื่อมต่อ repository ใหม่
5. ตั้งค่าฐานข้อมูลและ Secret ใหม่
6. ทดสอบระบบก่อนเผยแพร่
